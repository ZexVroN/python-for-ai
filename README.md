\### My First Python Program



```python

print("Hello, World!")

```



\### What I Learned



A Python program can be written inside a `.py` file and executed by the Python interpreter.



For example:



```bash

python hello.py

```



Python reads the program and executes the instructions sequentially.



I also learned that the \*\*Run\*\* button in VS Code is essentially a convenient way to execute the Python program through the configured Python interpreter.



\### Key Takeaway



> Before learning AI, I need to understand how Python programs actually run.
